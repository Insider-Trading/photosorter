# Photo Sorter - Keyboard Shortcuts

## Navigation
| Key | Action |
|-----|--------|
| `←` Left Arrow | Previous image |
| `→` Right Arrow | Next image |
| `Spacebar` | Skip to next image |

## Sorting (Quick Setup Default)
| Key | Category |
|-----|----------|
| `Q` | Face |
| `W` | Full Body |
| `E` | Upper Body |
| `R` | Landscape |
| `A` | Keep |
| `S` | Discard |
| `1-9` | Move to directory by position (1st, 2nd, 3rd, etc.) |
| `Delete` | Move to trash folder (auto-created) |

## Review & Undo
| Key | Action |
|-----|--------|
| `Ctrl+Z` | Undo last move |
| `f` | Flag/unflag current image |
| `Shift+F` | View only flagged images |

## Display Options
| Key | Action |
|-----|--------|
| `i` | Toggle metadata overlay (dimensions, size, aspect ratio) |

## Tips
- Hotkeys are shown in the sidebar next to each directory
- Number keys [1-9] provide quick access to the first 9 directories
- Flagged images have an orange "FLAGGED" badge
- The bottom-right corner shows a preview of the next image
- All settings are automatically saved between sessions
